# Development

Run `./tests/run` and `sha256sum -c SHA256SUMS`. Install with `omarchy theme install https://github.com/tcballard/omarchy-theme-tokyo-roadster`; this applies the theme and replaces an existing theme-tokyo-roadster installation. Preserve local edits and record the previous theme/background first.

On the XPS, check bar, launcher, menus, notifications, lock screen, focus/selected/disabled states, scaling, terminal/editor and GTK apps. Switch away and back, then restart the shell or log in again. Record actual results in ACCEPTANCE.json. A real desktop screenshot and media provenance confirmation remain prerequisites for registry submission.

Roll back with the theme picker and remove only this theme’s installed directory after preserving local changes.
