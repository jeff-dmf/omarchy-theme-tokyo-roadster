A separate Omarchy Quattro theme combining Tokyo Night's indigo surfaces, periwinkle blue shell accents and violet highlights with the approved, punchier Roadster wall-ride artwork. The original red Roadster theme is a separate installation.

## Install

Install and apply through Omarchy:

```bash
omarchy theme install https://github.com/tcballard/omarchy-theme-tokyo-roadster
```

This applies the theme and replaces any previous installation from this repository. Preserve local edits before reinstalling. Omarchy derives the installed name `theme-tokyo-roadster`. Switch back through the theme picker.

Uses Omarchy's built-in Tokyo Night semantic palette. Red remains an error colour; blue owns focus, selection borders, bar activity and notification countdowns. Font sizes and spacing stay native.

## Wallpaper

Includes the approved blue-violet wall-ride colourway as the only/default wallpaper. The image is exported at 8192 × 5461. This is a Lanczos enlargement of the approved 1536 × 1024 generated preview, preserving that artwork exactly; it has not received the two-pass contextual 8K enhancement used for the original red wallpaper set. The other seven photographs have not been recoloured.

## Compatibility

Targets Quattro source revision 51bfd1dbaa1b5f790e19623faf2745945d40c796. Four complete shell section overrides style bar, controls, launcher and menus; remaining shell and app configurations are generated by Omarchy. Check the four upstream sections when updating Quattro. See [validation evidence](docs/VALIDATION.md) for checks and live-testing limits.
