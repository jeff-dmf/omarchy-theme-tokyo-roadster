# Wallpapers

Nine Tokyo Roadster colourways, ordered wall-ride (default), lineup, hover, ramp, inverted, rear, diffuser, studio and the ROADSTER event poster. The approved wall-ride is unchanged. All are lossless sRGB PNG exports with an 8192-pixel longest edge, using proportional Lanczos enlargement of generated artwork. No additional two-pass contextual enhancement is claimed. See ../docs/WALLPAPER-GENERATION.json, ../CREDITS.md and ../SHA256SUMS.
